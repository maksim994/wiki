# Матрица ролей и прав

Три глобальные роли: **Admin**, **Editor**, **Viewer**. Права задаются на уровне системы; в MVP нет ACL на отдельные блоки внутри страницы.

## Обозначения

| Символ | Значение |
|--------|----------|
| ✅ | Разрешено |
| ❌ | Запрещено |
| ⚙️ | Только для своих объектов / в рамках назначенных space (см. ниже) |

## Глобальная матрица

| Действие | Admin | Editor | Viewer |
|----------|:-----:|:------:|:------:|
| Вход в приложение | ✅ | ✅ | ✅ |
| Просмотр страниц с доступом «внутренняя» / назначенные space | ✅ | ✅ | ✅ |
| Просмотр публичных страниц по публичной ссылке (без логина) | ✅ | ✅ | ✅ (и анонимно) |
| Создание space | ✅ | ❌* | ❌ |
| Удаление space | ✅ | ❌ | ❌ |
| Настройки space (название, участники) | ✅ | ⚙️** | ❌ |
| Создание страницы в space | ✅ | ✅ | ❌ |
| Редактирование содержимого страницы | ✅ | ✅ | ❌ |
| Перемещение страницы в дереве | ✅ | ✅ | ❌ |
| Удаление страницы (мягкое удаление) | ✅ | ✅ | ❌ |
| Восстановление из корзины | ✅ | ⚙️*** | ❌ |
| Изменение видимости страницы (private / internal / public) | ✅ | ✅ | ❌ |
| Включение публичной ссылки (с подтверждением) | ✅ | ✅ | ❌ |
| Просмотр истории версий и diff | ✅ | ✅ | ✅ (только чтение) |
| Откат к версии | ✅ | ✅ | ❌ |
| Комментирование страницы (если комментарии включены) | ✅ | ✅ | ✅ |
| Удаление чужих комментариев | ✅ | ❌**** | ❌ |
| Упоминания пользователей в тексте и комментариях | ✅ | ✅ | ✅ |
| Подписка на страницу / space | ✅ | ✅ | ✅ |
| Поиск по контенту | ✅ | ✅ | ✅ |
| Управление пользователями (создание, блокировка, смена роли) | ✅ | ❌ | ❌ |
| Приглашения (invite) | ✅ | ❌ | ❌ |
| Системные настройки (название инстанса, политики, SMTP) | ✅ | ❌ | ❌ |
| Просмотр аудит-лога административных действий | ✅ | ❌ | ❌ |
| Экспорт резервных копий (если предусмотрено UI) | ✅ | ❌ | ❌ |

\* В MVP по умолчанию только Admin создаёт space; опциональная настройка инстанса «разрешить редакторам создавать space» может быть добавлена позже — в базовой матрице создание space у Editor **запрещено**.

\** Editor может менять настройки space, если явно указан как **владелец space** (назначение только Admin); иначе только контент внутри.

\*** Editor может восстанавливать только страницы, которые сам удалил, если политика инстанса это разрешает; иначе только Admin.

\**** Модерация: Admin удаляет любые комментарии; автор может удалить свой комментарий в течение ограниченного времени (опционально в MVP).

## Видимость страниц

| Статус | Кто видит (авторизованные) | Аноним |
|--------|----------------------------|--------|
| **private** | Только пользователи, явно добавленные к странице или унаследовавшие доступ от родителя (если включено наследование) — в упрощённом MVP: только Admin и назначенные редакторы страницы | ❌ |
| **internal** | Все пользователи с доступом к parent space | ❌ |
| **public** | Все с ссылкой (и внутренние пользователи) | ✅ по публичному URL |

**Рекомендация для упрощения MVP:** не вводить per-page ACL для десятков пользователей; достаточно:

- уровня **space** (участники: все с ролью в системе или выбранный список),
- статуса страницы **private | internal | public**,
- опционально: «ограничить эту страницу только редакторами space» (флаг для чувствительных черновиков).

Если нужен только три роли без per-page списков, **private** в MVP можно трактовать как «видна только Editor+ Admin внутри space» или «только создатель + Admin» — это фиксируется в [CONTENT-MODEL.md](./CONTENT-MODEL.md).

## Итоговое правило

- **Admin** — полный контроль над инстансом, пользователями и всеми space.
- **Editor** — полный контент в доступных space: создание, редактирование, публикация, публичные ссылки с подтверждением.
- **Viewer** — чтение, поиск, комментарии, подписки; без правок контента и без администрирования.
