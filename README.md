# Корпоративная wiki (спецификация MVP)

Исходный репозиторий: [github.com/maksim994/wiki](https://github.com/maksim994/wiki).

Репозиторий содержит продуктовую и техническую документацию для self-hosted корпоративной wiki: закрытый доступ по умолчанию, роли Admin / Editor / Viewer, блочный редактор в духе Notion, поиск, версии, комментарии и публикация отдельных страниц наружу по ссылке.

| [docs/ROLES.md](docs/ROLES.md) | Матрица ролей и прав |
| [docs/CONTENT-MODEL.md](docs/CONTENT-MODEL.md) | Сущности, дерево страниц, публикация, версии |
